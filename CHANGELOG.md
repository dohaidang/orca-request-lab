# Changelog

All notable changes to Request Lab are documented here.

## 0.6.0

- Added privacy controls and body-free history by default.
- Added automatic redaction for sensitive headers and credential-like query parameters.
- Added portable workspace bundle import and export with environment values excluded by default.
- Hardened cookie domain handling and OAuth token-cache isolation.
- Added dependency-free repository validation and continuous integration.
- Added contribution and security documentation.

## 0.5.0

- Added OAuth 2.0 Client Credentials, token caching, GraphQL builder, and per-request runtime directives.

## 0.4.0

- Added OpenAPI import, session cookies, retries, and JSON/JUnit report export.

## 0.3.0

- Added assertions, response capture, collection runs, and code generation.

## 0.2.0

- Added environments, encrypted authentication, history, and cURL import.

## 0.1.0

- Initial HTTP workbench with `.http` and `.rest` support.
